What you get

Global Theme

Dark and Light, with its own splash screen and wallpapers.

Plasma Style and colours

Panels, popups and widgets, colour schemes and window borders.

Apps

A Kvantum style for Qt apps and a GTK theme for Firefox, GIMP and Inkscape, switched with the rest.

Icons and cursors

About 145 folder types, 600 app tiles and 260 file types; Breeze cursors recoloured.

Top panel

Launcher, tasks, a centred clock and system stats, in six looks from Normal to Fancy.

Terminal

Konsole colour schemes and profiles, and Fastfetch in the theme's colours.

One command

Switch everything between Dark and Light, with a Settings app for the rest.

COSMIC too

Dark and Light themes and wallpapers for the COSMIC desktop.

Install

KDE Plasma 6

  1. Download Natura-0.1.0.zip and unzip it.
  2. Run the installer: a guided setup in the terminal. Nothing changes until you press Install.
cd Natura-0.1.0
./install.sh

Afterwards, natura dark or natura light switches everything.

COSMIC

  1. Download Natura-COSMIC-0.1.0.zip (a separate download) and unzip it.
  2. Run ./install.sh: it puts the two theme files and the wallpapers in place. Nothing in COSMIC changes by itself.
  3. Open COSMIC Settings › Desktop › Appearance, choose Dark or Light, then Import, and pick the matching .ron file.
  4. Pick the wallpaper in Settings › Desktop › Wallpaper › Add image.
